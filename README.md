# HR Analytics Dashboard – Power BI

## 📊 Project Overview

This project is an interactive **HR Analytics Dashboard** developed using Microsoft Power BI to analyze employee workforce data and identify patterns related to employee attrition, demographics, salary, job roles, and employee satisfaction.

The dashboard converts HR data into interactive visual insights that can help understand workforce composition and attrition-related trends.

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Microsoft Excel
* Data Cleaning & Transformation
* Data Visualization
* Business Intelligence

## 📌 Key KPIs

* Total Employees
* Attrition Count
* Attrition Rate
* Average Employee Age
* Average Monthly Income

## 📈 Dashboard Analysis

The dashboard provides analysis across multiple HR dimensions:

* Education-wise employee analysis
* Education and attrition analysis
* Age-band analysis
* Years at company analysis
* Salary hike analysis
* Job role analysis
* Job satisfaction analysis
* Department filtering
* Employee workforce analysis

## 🎯 Key Dashboard Features

* Interactive KPI cards
* Department slicer
* Job Role slicer
* Donut chart
* Column chart
* Bar chart
* Line chart
* Funnel chart
* Matrix visualization
* Interactive filtering

## 🔄 Data Preparation

The data was prepared and transformed using Power Query before creating the dashboard.

Data preparation included:

* Data cleaning
* Data transformation
* Column preparation
* Categorization of employee attributes
* Creation of calculated metrics

## 🧮 Power BI / DAX

DAX was used to create calculated metrics and KPIs such as employee attrition metrics and attrition percentage.
